Soft sensing for bioprocess monitoring

CellSENSING investigates soft-sensing approaches for estimating key physiological and process variables in biotechnological processes by combining sensor data with data processing, mathematical modeling, and machine-learning methods.

Why CellSENSING?

Cell viability and physiological performance influence both process performance and product quality. These important biological variables are often determined by offline analytical methods, which introduce delays and provide measurements only at a relatively low frequency. Soft sensing uses continuously available sensor and process information to estimate such variables indirectly, supporting a faster response to process changes.

Application Areas

Yeast & Brewing

CellSENSING investigates yeast management and brewing-related processes, including physiological yeast characteristics and metabolic or process variables. The research scope includes yeast viability, yeast vitality, and beer-maturation metabolites such as diacetyl.

CHO Cell Cultivation

CellSENSING also investigates mammalian CHO cell cultivation in biopharmaceutical production, including viable cell density and viability. These project goals extend beyond the particular variables shown in this data application.

CellSENSING Data Platform

The CellSENSING Data Platform provides access to experimental bioprocess datasets generated within the CellSENSING project. It combines detailed information on the experimental datasets with interactive visualisation of inline and offline process data.

The datasets are organised by subproject. Each subproject provides a Data Information section describing the experimental context and a Data Visualisation section for interactive exploration of the corresponding process data.

Using Data Visualisation

Selecting Experiments

Choose the relevant subproject, then use the available experiment filters and selectors to focus the dashboard on experiments of interest.

Exploring Process Parameters

Expand a scientific group to initialise its measurement panels. Open an individual measurement panel to reveal its controls and plot.

Comparing Experiments

Use the experiment selector within a measurement panel to compare selected experiments and reactors in the same plot.

Visual Encoding

Use Color by and Marker by to encode available experiment metadata, making shared and differing experimental characteristics easier to inspect.

Inline and Offline Data

Data Source controls distinguish inline data, recorded by process sensors, from offline data obtained from sampled analysis. Offline interpolated data are generated from the available discrete offline measurements using PCHIP (Piecewise Cubic Hermite Interpolating Polynomial) interpolation to provide a time-aligned representation.

Interacting with Plots

Hover over traces to inspect values. Use the Plotly controls to zoom, pan, show or hide traces through the legend, and reset the view.

Interpreting the Data

The platform presents experimental process data for exploration and comparison. Interpret trends together with the experimental context provided in Data Information, including the conditions and measurement methods relevant to each subproject.

Terminology

Inline data
Measurements recorded directly during a process.
Offline data
Measurements obtained from samples analysed outside the process stream.
Experiment
A defined cultivation run or experimental condition in a subproject dataset.
Reactor
An individual cultivation vessel associated with an experiment.
